# Stellogistics

**Stop hunting through dozens of individual ILS towers to figure out why your factory stalled.**

**Stellogistics** is a quality-of-life mod for *Dyson Sphere Program* (BepInEx 5) that adds an interactive, customizable **Interstellar Logistics Overview Panel** directly onto the Starmap. Instead of inspecting Interplanetary Logistics Stations (ILS) one by one, Stellogistics aggregates every remote supply and demand slot across an entire **Planet** or **Star System** into a single, combined **Exports** and **Imports** dashboard.

- **Source Code**: https://github.com/BaCheetah/Stellogistics

---

## Why Stellogistics? (The Problem It Solves)

In mid-to-late game *Dyson Sphere Program*, a single star system can easily host 20–60+ Interplanetary Logistics Stations and dozens of Orbital Collectors across multiple planets. When a production chain slows down across the cluster:
- You don't want to click through 50 individual towers just to find out whether a planet is **exporting** or **importing** an item.
- You need to know immediately if a mining/smelting outpost has **run dry (`EMPTY 0%`)** or if a factory world is **starved for inputs (`STARVED 0%`)**.
- You want to filter out noisy items (like ubiquitous building malls or warpers) on specific worlds while keeping them visible on others.

**Stellogistics** gives you that macro-level visibility right from the Starmap—whether you're hovering over distant stars or inspecting a specific planet.

## Key Features

### 1. Combined Planet & Star System Logistics
- **One Row Per Item**: Combines all Remote Supply (**Exports**) and Remote Demand (**Imports**) slots for the same item across the selected Planet or Star System.
- **Complete Capacity & Hatched `+In-Transit` Breakdown**: Shows `Stored / Max` capacity, fill percentage, a **diagonal hatched bar extension** for inbound vessel cargo (`+In-Transit`), number of planets involved, and total station slots (`ILS` + Gas Giant Orbital Collectors `OC`).
- **Fleet & Warper Readiness**: Header displays total ILS & Orbital Collector counts, idle vs. total Logistics Vessels, and available Space Warpers.

### 2. Galaxy Item & Bottleneck Finder (`Finder`)
- **Cluster-Wide Search & Bottleneck Scanner**: Locate every planet exporting or importing checked items across the entire star cluster, or toggle **`! ≤40% Only`** to scan all checked items for shortages (`EMPTY`, `STARVED`, `LOW`).
- **Click-to-Focus & Starmap Pin**: Click any planet row in the Finder to automatically focus that planet on the Starmap and set your yellow navigation indicator line. Click any item row to drill down to that item, and use **`← All`** to return to your Finder overview.
- **Planet & Star System Ignore Filter**: Exclude abandoned or starter worlds from Finder scans via the inline **`[✕]`** button on Finder rows, the **`Planets`** tab in the Picker, or the toggle in **`Filter ▾`**.

### 3. Instant Bottleneck, Throughput & Hub Detection
- **Color-Coded Health Bars & Badges**:
  - **Red (`EMPTY` / `STARVED` / `LOW`, ≤15%)**: Critical bottleneck—an export source has run out of stock to ship, or an import destination is starved.
  - **Orange (`LOW`, ≤40%)**: Stock is depleting and approaching a shortage.
  - **Green (>40%)**: Healthy buffer.
- **Logistics / Vessel Throughput Bottleneck Indicator (`⚡+ILS`)**:
  - Automatically flags importing planets (`⚡+ILS`) whose storage + inbound vessels (`+In-Transit` hatched bar) do not fill capacity while healthy/unclaimed export stock is sitting ready on another planet in the cluster—telling you immediately when you need another importing ILS tower or more vessels rather than more production.
- **Planet & System Hub Detection (`⇄ Hub`)**:
  - Automatically detects planets that both import and export the same item and displays a `⇄ Hub (Imp ...)` / `⇄ Hub (Exp ...)` badge with the counterpart capacity right on the row.
- **Section Header Alert Counters**: Even when the Exports or Imports sections are collapsed, the header displays instant alert tallies (e.g., `2 EMPTY • 1 LOW`).
- **One-Click Sorting (`Sort: Alert` / `Sort: ID` / `Sort: Pct ↓`)**: Sort ascending by fill percentage (`Alert`), by item ID, or descending by fill percentage (`Pct ↓`).

### 4. Smart Star System Trade Modes
When viewing a whole **Star System**, cycle between three aggregation modes:
- **`Ext Only` (Interstellar Smart)**: Automatically hides purely local intra-system shuttling (e.g. Planet A mining ore for Planet B's smelters inside the same system, or stations limited to `< 1 LY` range) so you only see true interstellar imports and exports.
- **`Netted` (Net Intra-System)**: Nets internal star system supply against internal demand.
- **`All Slots`**: Displays every remote supply and demand slot across all planets in the system.

### 5. Unified Item, Building & Planet Picker (`Filter ▾` & `Pick Item`)
- **6 Quick Category Checkboxes & Threshold Filter**: Quickly toggle item categories or hide full/tapped storages (`≥90%` / `100%` / `>40%`).
- **Unified `14 × 8` Picker (`Items`, `Buildings`, `Planets`)**:
  - One shared, spoiler-free picker window across both Starmap filtering and the Galaxy Finder, with **`✓ Check All`**, **`✕ Uncheck All`**, and **`! ≤40% Only`** controls.

### 6. Flexible Window Management & `Options ▾`
- **Dedicated `Options ▾` Menu**: Toggle the hatched `+In-Transit` bar, Gas Giant Orbital Collectors (`OC`), Starmap hover behavior, or reset UI position and size.
- **Freely Draggable & Resizable (`◢`)**:
  - Supports custom heights (including intentional empty space without snapping back), responsive two-row header button stacking at narrow widths, and multi-stage drag collapsing into a compact **`Stellogistics` taskbar tab**.

## Configuration

A configuration file is generated at `BepInEx/config/com.stellogistics.dsp.cfg` after first launch, storing your custom panel layout, thresholds, and saved per-star/per-planet filters.

## Source Code & How to Compile Yourself

The full source code is openly available at:
https://github.com/BaCheetah/Stellogistics

If you prefer to inspect the code and compile the `.dll` yourself rather than using a prebuilt binary, you don't even need *Dyson Sphere Program* installed on the build machine—all game and BepInEx reference assemblies are fetched automatically via NuGet.

### Prerequisites
1. Install the **[.NET SDK](https://dotnet.microsoft.com/download)** (any modern version such as .NET 6, 8, or newer).

### Step-by-Step Build Instructions
1. **Clone or download the repository**:
   ```powershell
   git clone https://github.com/BaCheetah/Stellogistics.git
   cd Stellogistics
   ```
   *(Or click **Code → Download ZIP** on https://github.com/BaCheetah/Stellogistics and extract it to a folder.)*

2. **Build the project in Release mode**:
   ```powershell
   dotnet build -c Release
   ```
   This restores the required NuGet reference packages (from `nuget.org` and `nuget.bepinex.dev`), compiles `Stellogistics.dll`, and packages everything automatically.

3. **Locate the compiled output**:
   - **Compiled Plugin DLL**: `bin/Release/net472/Stellogistics.dll`
   - **Thunderstore-Ready Folder**: `dist/package/`
   - **Thunderstore Mod Manager ZIP**: `dist/Stellogistics-2.1.0.zip`

4. **Install manually**:
   - Copy `Stellogistics.dll` into your `BepInEx/plugins/Stellogistics/` folder (or import `dist/Stellogistics-2.1.0.zip` as a local mod in Thunderstore Mod Manager / r2modman).
